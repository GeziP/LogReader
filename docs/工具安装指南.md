## 概述

LogReader 项目需要以下开发工具：

- **LLVM/Clang**：用于代码格式化和静态分析
- **Cppcheck**：用于静态代码分析
- **Python**：用于脚本和预提交钩子
- **vcpkg**：用于 C++ 包管理

本指南说明如何在 D 盘安装这些工具，以更好地管理磁盘空间。

## 系统要求

- **操作系统**：Windows 10 或更高版本
- **磁盘空间**：D 盘至少有 5GB 可用空间
- **PowerShell**：5.0 或更高版本
- **管理员权限**：安装需要

## 安装流程

### 自动安装

安装所有所需工具的最简单方法是使用提供的 PowerShell 脚本：

1. **以管理员身份打开 PowerShell**

2. **导航到项目根目录**
   ```powershell
   cd path\to\LogReader
   ```

3. **运行安装脚本**
   ```powershell
   .\scripts\setup_windows_d_ascii.ps1
   ```

4. **等待完成**
   脚本将：
   - 创建 D:\DevTools 目录结构
   - 下载并安装 LLVM、Cppcheck、Python 和 vcpkg
   - 配置环境变量
   - 安装 pre-commit 和其他依赖项

### 脚本执行的操作

安装脚本执行以下操作：

1. **创建目录结构**：
   - D:\DevTools
   - D:\DevTools\LLVM
   - D:\DevTools\Cppcheck
   - D:\DevTools\Python
   - D:\DevTools\vcpkg

2. **下载并安装工具**：
   - LLVM 16.0.0（包括 clang-format 和 clang-tidy）
   - Cppcheck 2.12.0
   - Python 3.11.5
   - vcpkg（最新版本）

3. **设置环境变量**：
   - 将工具路径添加到系统 PATH
   - 配置 vcpkg 集成

4. **安装依赖项**：
   - 通过 pip 安装 pre-commit
   - 通过 vcpkg 安装 Microsoft GSL

## 手动安装

如果自动脚本失败，可以手动安装工具：

### LLVM/Clang

1. 从 [LLVM 发布页面](https://github.com/llvm/llvm-project/releases/download/llvmorg-16.0.0/LLVM-16.0.0-win64.exe) 下载 LLVM 16.0.0
2. 运行安装程序并将安装路径设置为 D:\DevTools\LLVM
3. 将 D:\DevTools\LLVM\bin 添加到系统 PATH

### Cppcheck

1. 从 [Cppcheck 发布页面](https://github.com/danmar/cppcheck/releases/download/2.12.0/cppcheck-2.12.0-x64-Setup.msi) 下载 Cppcheck 2.12.0
2. 运行安装程序并将安装路径设置为 D:\DevTools\Cppcheck
3. 将 D:\DevTools\Cppcheck 添加到系统 PATH

### Python

1. 从 [Python.org](https://www.python.org/ftp/python/3.11.5/python-3.11.5-amd64.exe) 下载 Python 3.11.5
2. 运行安装程序并将安装路径设置为 D:\DevTools\Python
3. 将 D:\DevTools\Python 和 D:\DevTools\Python\Scripts 添加到系统 PATH
4. 安装 pre-commit：`D:\DevTools\Python\python.exe -m pip install pre-commit`

### vcpkg

1. 从 [GitHub](https://github.com/microsoft/vcpkg/archive/refs/heads/master.zip) 下载 vcpkg
2. 解压到 D:\DevTools\vcpkg
3. 以管理员身份打开 PowerShell 并运行：
   ```powershell
   cd D:\DevTools\vcpkg
   .\bootstrap-vcpkg.bat
   .\vcpkg integrate install
   .\vcpkg install ms-gsl:x64-windows
   ```

## 验证安装

要验证所有工具是否正确安装：

1. **打开新的 PowerShell 窗口**

2. **检查 LLVM/clang-format**
   ```powershell
   D:\DevTools\LLVM\bin\clang-format --version
   ```
   预期输出：`clang-format version 16.0.0`

3. **检查 Cppcheck**
   ```powershell
   D:\DevTools\Cppcheck\cppcheck --version
   ```
   预期输出：`Cppcheck 2.12.0`

4. **检查 Python**
   ```powershell
   D:\DevTools\Python\python.exe --version
   ```
   预期输出：`Python 3.11.5`

5. **检查 vcpkg**
   ```powershell
   D:\DevTools\vcpkg\vcpkg version
   ```
   预期输出：vcpkg 的版本信息

6. **检查 pre-commit**
   ```powershell
   D:\DevTools\Python\Scripts\pre-commit --version
   ```
   预期输出：`pre-commit 4.x.x`

## 问题排查

### 常见问题

#### 下载失败

如果遇到下载失败（403 错误、SSL/TLS 错误等），手动下载文件并放置在适当位置：

- LLVM：https://github.com/llvm/llvm-project/releases/download/llvmorg-16.0.0/LLVM-16.0.0-win64.exe
- Cppcheck：https://github.com/danmar/cppcheck/releases/download/2.12.0/cppcheck-2.12.0-x64-Setup.msi
- Python：https://www.python.org/ftp/python/3.11.5/python-3.11.5-amd64.exe
- vcpkg：https://github.com/microsoft/vcpkg/archive/refs/heads/master.zip

#### 目录存在但为空

脚本会检查目录是否为空或缺少关键文件，并在必要时重新安装。

#### 权限问题

确保以管理员身份运行 PowerShell。

#### 路径过长错误

如果在 vcpkg 安装期间遇到"路径过长"错误，考虑将 vcpkg 目录移动到更接近根目录的位置（例如，D:\vcpkg）。

#### Python 安装失败

如果 Python 安装失败，尝试手动安装，取消勾选"添加 Python 到 PATH"选项，然后手动添加路径。

### 获取帮助
